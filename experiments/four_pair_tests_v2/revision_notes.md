# 四项实验修订说明

基线为 cf9ced9 的 four_pair_tests。旧目录和原始数据库保留。原版 run.py 的 entry_test 每日恢复双腿权重，不能代表固定股数；方向检验从连续账户截取日收益，展示表却使用测试期独立账户；实验三缺训练期及完整成本指标；实验四把同标的按两腿收费，并以多头收益充当共同项。

修订代码在 run.py。实验一将两种持仓规则放在相同窗口逐日结算。实验二从同一独立测试账户生成检验、图和统计表。实验三记录每个信号的信息截止日、更新频率、回退及实际持仓。实验四先净额合并同一标的，再按对称分解逐日归因。verify.py 以独立公式检查交易日、头寸、现金流、收益归因、动态信号和配对检验。各项数值变动与研究限制见正式报告及 results/version_comparison.csv。

| 实验 | 修订后主要变化 | 独立核验 |
|---|---|---|
| 一 | 原报告均值−1.83%对应每日调仓。按初始资金各建仓50%并固定数量后，平均净收益−1.89%，最差窗口−12.49%。 | 两种规则各2,632笔、252个持有日的毛净路径均通过检验。固定数量另用端点价比及实际空头名义计算。 |
| 二 | 保留三对原选向。5阶HAC原始p值改为0.5075、0.7170、0.6793。测试账户完整支付建仓和平仓成本。 | 逐日配对差与独立账户一致，5、10、20阶共9项标准误、p值及Holm校正均经独立公式复核。 |
| 三 | 训练期共同预热，验证期、测试期分别开仓。六方向测试期的平均年化净波动，等额为2.77%、每日EWMA为2.48%；对应平均累计净收益为−2.19%、−2.22%。 | 核对估计截止日、日／周／月／季更新日、持仓漂移、收益、成交与费用。训练启用后及验证、测试期均无无效比率回退。 |
| 四 | 同指等额净收益由−2.08%改为0；不同指数的等额测试账户净收益由−4.62%改为−4.67%。静态跨指的毛账户共同贡献由+0.61改为+1.06个百分点。 | 核对净额成交、实际借券、两项毛贡献之和，以及净账户“共同＋相对−交易费−借券费”与期末损益的勾稽。 |

核验涉及298个分阶段账户、289,598个账户日。训练期静态OLS使用最初120日拟合；验证与测试使用训练期结束前可执行的冻结估计。这一约定避免把训练末估计倒用于训练初期。输入为价格指数，同源原始行情核验与交易日历比对已完成；真实分红、ETF成交、期货基差、保证金及实际借券费率仍超出本次价格模拟。测试期是历史留出，仍受既有研究关注与样本长度限制。
