# 指数行情库说明

数据库为 `a_share_indices.sqlite`，固定研究池包含九条日度**价格指数**。本次补入三条序列，沿用原库的行情截止日2026-11-17。

初版六条序列由 AKShare `index_zh_a_hist` 访问东方财富取得。新增三条序列由 AKShare `stock_zh_index_daily` 访问新浪财经取得，包含开高低收和成交量。新浪接口未返回的成交额、换手率和来源涨跌幅等字段在 SQLite 中为空。`raw_index/` 保存源接口规范化后的 CSV 快照，`ingest_batch` 保存抓取时间、接口、版本、请求区间、行数及 SHA-256 校验值。`ingest_report.json` 为初版记录，[ingest_report_nine.json](ingest_report_nine.json) 为本次新增批次记录。

## 表结构

- `index_master`：指数代码、名称、提供方和收益类型。代码与行情供应商组合使用。
- `index_daily`：每日开高低收、成交量、成交额、来源涨跌幅、按收盘价计算的简单收益率及对应批次。`close_return`以小数表示，每条指数在库中第一个收盘日的收益率为空。来源涨跌幅`change_pct_source`以百分数表示。
- `ingest_batch`：来源追溯和原始快照校验信息。

## 初版六指数验收

每条指数2,884条日线，范围2015-01-05—2026-11-17；其中2015—2025年2,674条。六条交易日完全对齐。SQLite完整性检查通过；无重复交易日、周末记录、OHLC矛盾或收盘收益与来源涨跌幅超过0.05个百分点的差异。与国证指数官方399311接口核对2025-01-02—2025-01-10七个交易日，最大收盘点位差0.0049，符合东方财富两位小数与国证四位小数的精度差异。

## 使用示例

```python
import sqlite3
conn = sqlite3.connect('data/a_share_indices.sqlite')
rows = conn.execute('''
  SELECT trade_date, close, close_return
  FROM index_daily
  WHERE provider='eastmoney' AND index_code='000300'
    AND trade_date BETWEEN '2015-01-01' AND '2025-12-31'
  ORDER BY trade_date
''').fetchall()
```

## 当前数据边界

行情部分仅有**价格指数**。本次扩展覆盖新增三条指数的日线，成分股和权重另行采集。历史成分覆盖见[成分股覆盖说明](constituent_coverage.md)。东方财富与新浪财经的精度和成交量口径可能不同。内部贡献复制应优先比对指数公司点位，并使用当期有效权重。
