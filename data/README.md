# 指数行情库说明

数据库：`a_share_indices.sqlite`。本次抓取六条指数2015-01-01至2026-11-17的日度**价格指数**行情；实际首日为2015-01-05。2015—2025年为研究样本，2026年数据供后续更新及观察使用。

数据由本地 AKShare `index_zh_a_hist` 接口访问东方财富日线接口取得。`raw_index/`保存每条指数本次抓取的标准化CSV快照，`ingest_batch`保存抓取时间、接口、版本、请求区间、行数和SHA-256校验值。CSV是AKShare字段映射后的快照，不是未经转换的HTTP响应。重新执行 `python scripts/build_index_db.py` 可追加新抓取批次，并按主键更新日线。`ingest_report.json`记录本次结果。

## 表结构

- `index_master`：指数代码、名称、提供方和收益类型。代码与行情供应商组合使用。
- `index_daily`：每日开高低收、成交量、成交额、来源涨跌幅、按收盘价计算的简单收益率及对应批次。`close_return`以小数表示，来源涨跌幅`change_pct_source`以百分数表示；请求区间首日的`close_return`为空。
- `ingest_batch`：来源追溯和原始快照校验信息。

六条指数代码：399311国证1000，000903中证A100，000132上证100，000300沪深300，000001上证综合指数，000985中证全指。000903在早期历史时期沿用原中证100规则，名称在主表中表示当前名称；研究历史选样规则时须查规则版本。

## 本次验收

每条指数2,884条日线，范围2015-01-05—2026-11-17；其中2015—2025年2,674条。六条交易日完全对齐。SQLite完整性检查通过；无重复交易日、周末记录、OHLC矛盾或收盘收益与来源涨跌幅超过0.05个百分点的差异。与国证指数官方399311接口核对2025-01-02—2025-01-10七个交易日，最大收盘点位差0.0049，符合东方财富两位小数与国证四位小数的精度差异。

## 使用示例

```python
import sqlite3
conn = sqlite3.connect('data/a_share_indices.sqlite')
rows = conn.execute('''
  SELECT trade_date, close, close_return
  FROM index_daily
  WHERE provider='eastmoney' AND index_code='000300'
    AND trade_date BETWEEN '2015-01-01' AND '2025-12-31'
  ORDER BY trade_date
''').fetchall()
```

## 当前数据边界

行情部分仅有**价格指数**，没有全收益指数或ETF净值。成分股数据已另行入库，具体覆盖与缺口见[成分股覆盖说明](constituent_coverage.md)。目前可用于指数点位、价格收益、状态划分及初步Beta分析；投资价值正式比较还需全收益口径，内部抵消计算还需连续历史权重。东方财富点位保留两位小数，做精细贡献复制时应优先与指数公司更高精度行情核对。2026-11-17为本次抓取结束日，不意味着所有数据均已通过指数公司逐日核验。
