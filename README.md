# A股宽基指数研究：项目历程、实验结果与当前结论

> **研究档案更新：2026-11-25**  
> 本 README 按研究问题实际演进顺序记录项目从最初假说、数据建设、实验设计、结果修订到当前研究边界的全过程。它是项目导航和研究日志，不替代各实验报告中的完整模型、统计表、代码与复现记录。

**核心研究对象：** A股宽基价格指数。  
**核心研究问题的演变：** 宽基内部收益如何抵消、指数之间能否形成可投资的相对收益、长期排名是否由少数交易日决定、指数曲线的相似性如何衡量，以及共同市场波动下是否存在持续的局部相对收益漂移。

---

## 一、项目从哪里开始：最初的研究动机

项目最初并不是为了证明某个指数长期优于另一个指数，而是从一个更基础的观察出发：

**宽基指数看起来分散了个股风险，但指数收益究竟是成分股普遍同向推动的结果，还是大量个股、行业的正负贡献相互抵消后形成的净结果？不同宽基之间的历史收益差异，能否被投资者转化为扣除成本后仍然成立的收益？**

由此形成三个早期问题：

1. **指数内部：** 同一交易日，成分股正负收益贡献相互抵消多少？抵消主要发生在行业内部还是行业之间？
2. **指数之间：** 宽基指数的市场与风格暴露有何不同？多宽基组合能否改善风险收益？
3. **相对价值：** 如果历史上A指数跑赢B指数，冻结方向、建仓时点和对冲规则后，能否继续取得正的净收益？长期领先是否依赖少数交易日？

项目早期把这些问题放在同一个研究框架中，但它们并非同一个统计命题：指数内部的横截面抵消、长仓组合绩效、两腿配对账户和长期相对财富归因，必须使用不同的计量对象和资金口径。

## 二、第一阶段：宽基指数的市场暴露、内部抵消与配置价值

**研究目标：** 先描述宽基指数的风险结构，再检查指数内部的收益抵消，以及多宽基组合是否具有配置价值。

这一阶段形成了E1—E8实验框架。

### E1：双基准市场暴露

用上证综指和中证全指分别作为市场基准，估计四条目标宽基的Beta。

主要结果：

- 国证1000相对上证综指的Beta为1.088，换成中证全指后为0.955。
- 中证A100相对上证综指的Beta为1.004，相对中证全指为0.816。
- 上证100相对上证综指的Beta为1.125，相对中证全指为1.041。
- 沪深300相对上证综指的Beta为1.043，相对中证全指为0.876。
- 8项截距校正后均未检出显著结果；7项Beta显著不同于1，中证A100相对上证综指的Beta是例外。

**阶段结论：** 宽基指数的风险暴露会随基准定义而改变，不能把某一条指数的Beta解释成不依赖基准的固定属性。较高相关性也可能来自成分重叠和共同市场因子。

### E2：历史行情状态下的表现

按上证综指此前120日收益和均线位置，将市场划分为主升、震荡、下跌和过渡状态，并比较条件收益、波动与回撤。

主要结果：

- 四条指数在下跌状态中的年化条件波动最高，约24.73%—33.47%。
- 规则状态下，四条指数震荡组平均次日收益为正、主升组为负，但与过渡组的均值差经Holm校正后均不显著。
- Markov三状态样本外分类高度集中，不能为状态间收益差提供有力交叉验证。

**阶段结论：** 行情状态可以用于描述历史条件表现，但本轮没有得到稳健的状态择时收益证据。

### E3：风格暴露与截距

将市场模型扩展为CH-3、CH-4风格模型，加入规模、价值和异常换手因子。

主要结果：

- 风格因子提高了部分指数模型的调整R²。
- 中证A100相对沪深300的调整R²从市场模型的0.076提高到CH-3的0.417。
- 沪深300在CH-4价格收益回归中的负截距经校正后达到5%显著水平，线性年化约−3.48%，但价格指数未计分红，且因子资产收益口径可能不同，不能据此认定全收益Alpha。

**阶段结论：** 市场Beta不能解释全部指数收益差异，规模、价值等风格暴露值得控制；截距结果依赖收益口径和模型设定。

### E4—E5：成分股收益抵消与行业分解

使用2026-10-30收盘权重和随后两日个股不复权收益，计算成分股贡献。

2026-11-02快照结果：

| 指数 | 正负贡献绝对值抵消率 |
|---|---:|
| 国证1000 | 46.97% |
| 中证A100 | 66.02% |
| 上证100 | 24.89% |
| 沪深300 | 63.39% |

对国证1000可匹配的行业子样本进一步分解，行业内部抵消107.21bp、行业间抵消6.61bp；该日行业内部抵消占总抵消的94.19%。

**阶段结论：** 单日横截面上，宽基内部确实可能存在大量正负贡献抵消，且行业内部抵消可能占主导。但目前这只是有限日期的快照，不能推断长期稳定规律。

### E6—E7：行业轮动与抵消率预测

原计划继续研究连续震荡期的行业贡献轮动，以及抵消率能否预测未来波动和回撤。

**状态：受数据限制，尚未形成可报告的实证结果。** 缺少连续、同口径的历史有效成分权重、个股收益和行业归属面板。代码入口保留，但不能把研究假说写成已经验证的结论。

### E8：多宽基组合的增量价值

比较单指数、月度等权和滚动最小方差组合。

主要结果：共同样本外、每单位成交10bp成本情景下，动态最小方差组合年化波动约18.33%，月度等权约18.68%；夏普分别约0.251和0.213，但两者夏普差的Bootstrap区间包含零。动态组合年化成交金额约为资产的105.9%，月度等权约23.6%。

**阶段结论：** 最小方差组合降低波动的证据较清楚，但夏普改善和实际配置价值仍不确定；高换手也带来执行成本问题。

本阶段的完整方法、表格和局限见[综合研究报告](reports/integrated/research_report.md)及[初步报告](reports/preliminary_report.md)。

## 三、第二阶段：从相对强弱观察转向多空配对交易

**研究动机：** 如果两条宽基长期表现存在差异，能否通过做多相对强势指数、做空相对弱势指数，构造可执行的相对价值策略？

早期曾对上证综指与沪深300建立多空账户。最初的示例使用每1元净资产做多1元上证综指、做空约0.820元沪深300，总名义敞口约1.82倍。2021-01-04至2026-11-17的全期毛收益约27.03%；将总名义敞口归一到1倍后约14.26%。等金额做多1元、做空1元的毛收益约31.00%，但总敞口是2倍。

这些数字暴露出一个关键问题：**不同资金分母、不同总敞口的收益率不能直接比较。** 后续实验统一资金口径，明确多空头寸、交易费、借券费、调仓和期末平仓。

### 四项基础配对实验

| 实验 | 要回答的问题 | 主要结果 |
|---|---|---|
| 实验一：建仓时点 | 同一方向持有252日，结果是否取决于进入日期？ | 2015—2026年2,632个窗口中，做多上证综指、做空沪深300的固定数量账户平均净收益−1.89%，每日恢复权重账户−1.83%；净盈利窗口占比分别约32.29%和29.75%。 |
| 实验二：方向选择 | 验证期选出的多空方向，能否在独立测试期跑赢反向？ | 三组方向中两组在测试期跑赢反向，但仅一组净收益为正；三组方向差异经Holm校正均不显著。 |
| 实验三：对冲比率 | OLS、滚动OLS、EWMA和波动率比能否改善风险？ | 每日EWMA将六个方向的平均年化波动从约2.77%降至2.48%，但平均净收益仍为负。控制共同波动不等于预测相对收益。 |
| 实验四：同指数与跨指数 | 两腿是否真是两个独立风险头寸？ | 同指数等额多空净额结算后毛收益、成交和借券费用均为零；跨指数等额多空仍承担相对收益和两腿成本。 |

**阶段结论：** 对冲比率主要解决给定方向下的共同波动和头寸风险，不能替代对相对收益方向的预测。历史选向没有获得稳定、显著且覆盖成本的收益证据。

详细结果见[四项配对实验报告](experiments/four_pair_tests/research_report.md)及[修订版报告](experiments/four_pair_tests_v2/research_report.md)。

### 六指数策略网格与可执行性检查

之后将搜索扩展到六条指数、多个多空方向、对冲估计方法和更新频率。测试期验证锁定的沪深300多头／上证100空头策略，60日波动率比的测试累计毛收益约3.06%，在单边5bp交易费和年化2%借券情景下净收益约0.49%。

测试期回看选出的冠军表现更好，但这不能作为事前选择结果。实际ETF、股指期货、借券可得性、基差、保证金和跟踪误差也会改变结果。

### 多维策略搜索：检查“历史冠军”是否只是事后赢家

在八类规则中生成1,245个去重候选。全历史事后冠军累计净收益80.02%、年化5.27%、最大回撤16.42%；但按历史信息逐窗选择后，收益选择规则从2018年起累计−44.42%，综合选择规则累计−11.54%，预设理想门槛下没有合格解。

**阶段结论：** 搜索空间越大，越容易在历史中找到漂亮曲线；但历史冠军并没有转化为可靠的时序选择能力。该结果提醒我们控制多重检验、参数搜索和研究者事后选择偏差。

## 四、第三阶段：关键交易日是否决定长期相对收益？

**研究问题的转折：** 在沪深300与上证综指的配对回测中，我们发现两条指数长期财富差并不大，而且方向会随观察区间变化。于是研究从“如何交易”转向“长期相对收益究竟由哪些交易日形成”。

### 沪深300与上证综指：关键日删帧实验

样本为2015-01-05至2026-11-17，共2,884个收盘点、2,883个收益日。

主要发现：

- 上证综指累计价格收益约6.99%，沪深300约9.20%；两者相对价格财富优势约2.07%。
- 相对日收益的正贡献合计3.74144，负贡献合计−3.72098，对冲后的净额只有0.02046；正负贡献抵消率约99.73%。
- 沪深300领先的交易日占48.56%，落后的交易日占51.44%，并不是多数交易日都在领先。
- 删除事后最有利于沪深300的1日后，财富优势还剩约0.37%；删除2日后变为−1.17%，长期领先关系翻转。
- 日相对对数收益均值约0.071bp，HAC检验p=0.916，没有显著正漂移。
- 在固定历史上随机删除10%交易日，终值领先翻负的频率约36.98%。这描述的是对既有历史删帧的敏感性，不是未来收益概率。

同时发现，日收益拟合度、累计路径距离和终点财富差是不同概念。删去最大分化日可以提高日收益R²、降低累计路径RMS，却改变最终排名；不能用一个“相似度”指标替代全部问题。

**阶段结论：** 长期终值优势对少数事后关键日高度敏感，但没有证据证明沪深300拥有稳定正的相对收益漂移。删除关键日是历史反事实，不是可执行的择时策略。

## 五、第四阶段：从两条指数扩展到九条宽基

**研究目标：** 检查“少数关键日影响长期相对排名”是否只存在于沪深300与上证综指，还是在更广泛的宽基指数配对中普遍出现。

新增中证500、创业板指和科创50后，九指数形成36组无序配对。主样本为2020-07-23收盘至2026-11-17收盘，共1,531个日对数收益。

主要结果：

- 36组中有31组，删除不超过约1%的交易日便会失去历史领先；翻转所需日数中位数为4日。
- 但最有利的5日只占全部正贡献的3.26%（配对中位数），只有2组同时满足“低翻转日数”和“前五日贡献至少5%”两个条件。
- 正负相对收益抵消率中位数为98.61%。小的净领先容易翻转，并不等于正向贡献本身集中在极少数日。
- 五种同步区块零漂移模拟没有发现全池关键日集中度或日期重合异常偏高。
- 过去一年集中度对未来20日、60日相对风险的滚动样本外预测没有达到预设标准；中位增量样本外R²为负。

九指数全路径比较还显示，科创50与其余七条的平均路径距离较大，创业板指也相对分散；但“科技行业集中导致分离”仍需要历史行业权重和成分数据验证，不能从指数收盘价直接识别因果机制。

**阶段结论：** 终值排名对少数交易日敏感，在九指数配对中相当普遍；但贡献集中度异常、关键日异常重合和集中度预测未来风险这三个更强命题没有得到支持。

## 六、第五阶段：七指数关键日集合、重合度与路径趋同

九指数研究中，科创50和创业板指相对其余指数更分散。为先研究较接近的宽基群体，暂时排除这两条科技板块指数，保留七条：

- 上证综指（000001）
- 中证全指（000985）
- 沪深300（000300）
- 中证A100（000903）
- 上证100（000132）
- 国证1000（399311）
- 中证500（000905）

七条指数构成21组配对。

### 七指数V2：关键日名单是否统一？

每组分别选出前10个关键日，共210个名额；去重后得到56个日期，其中37日至少被两组提名，严格交集为空。配对间平均Jaccard为0.185；共享一条指数的配对名单平均重合度0.246，不共享指数的配对为0.124。

关键日确实有跨配对的共同性，但共同日期并不意味着删掉这些日期后曲线会靠拢。

### 七指数V2：共同删日与独立删日

四种共同名单方案（整体分化、并集、重复集合、投票）在主设定下都扩大七指数全池累计路径RMS。每组独立删除自身关键日时，21组中19组路径距离扩大、2组缩小。

随机删日和同步区块对照进一步表明：这些删日方案没有表现出稳定、显著优于等量随机删日的全池路径改善能力。共同日期、收益贡献方向和累计路径距离是三个不同对象。

[七指数V2报告](experiments/seven_index_convergence_v2/research_report.md)。

### 路径相似度纠偏：为什么固定起点RMS会误导？

观察曲线图时发现一个问题：如果两条指数在研究早期已经形成固定差距，即使后半段走势几乎平行，固定第一个交易日的累计净值RMS仍会持续记录这段历史差距。

因此，项目开始区分：

1. **固定起点累计路径距离：** 长期财富位置差异和差距累积。
2. **窗口重置距离：** 每个60、120、252日窗口重新对齐起点，衡量窗口内部新形成的路径偏离。
3. **段内中心化／去趋势形状距离：** 去除长期平均位置或线性漂移后，比较曲线局部形态。

这些指标回答不同问题，不能相互替代。

### 七指数后半段平行性与V3复核

早期段内中心化比较发现，原始行情21组中有15组在后半段比前半段更平行；但V3进一步用窗口重置RMS、同步区块Bootstrap重新检查。

V3结果：

- 固定起点的全池距离从前段约7.12升至后段约14.63个对数点。
- 但完全落在各自半段内的252日重置窗口距离中位数从约5.45降至4.89个对数点。
- 60、120、252日窗口的典型距离均有下降，后半段日收益相关系数中位数也较高。
- 同步区块Bootstrap没有发现这些前后变化显著超出稳定联合收益过程的范围。

因此，**“后半段局部路径更接近”可以作为样本描述，但没有得到显著结构变化证据。**

### 四种关键日名单在多期限下的表现

将V2关键日名单重新用于V3的窗口重置距离：

- 主设定K=10时，四种名单都使60日距离缩小。
- 同时，四种名单都使252日距离扩大。
- 与相同数量的随机删日比较，最小Holm校正p值为0.246，没有显著的额外改善。

**阶段结论：** 路径距离必须与观察期限和起点处理方式一起定义。早期偏移可以让长期曲线平行却不重合；短期窗口更近，也不代表长期财富差距缩小。当前没有证据证明关键日删除会普遍改善指数路径相似性。

## 七、第六阶段：重新聚焦沪深300与上证综指——共同市场波动与连续相对偏移

七指数研究暴露出一个更基础的问题：指数之间高度相关，并不意味着相对收益差可以由共同市场波动解释。研究因此重新回到最初的沪深300与上证综指配对，但这次不再只关注长期终点，而是研究连续持有期中的相对收益速度。

定义：

- 日相对收益：`d_t = r_{300,t} - r_{SSE,t}`
- 累计偏移：(D_t=\sum_{s\le t}d_s)
- W日平均相对收益速度：(v_t(W)=W^{-1}\sum_{s=t-W+1}^{t}d_s)

中证全指作为共同市场波动代理。价格指数未计现金分红。

### V1：相对收益速度、市场暴露与时变Beta

主要结果：

1. 沪深300全期相对上证综指的价格财富优势仍为2.07%；中和最有利的两个交易日后，终值翻转。
2. 但60日相对收益速度峰值仍出现在2017-11-21，达到13.50bp/日；最弱60日窗口结束于2026-10-21，约−17.01bp/日。
3. 固定市场斜率差约0.0432，只解释约3.28%的日相对收益差方差。
4. 上涨日相对斜率约0.1025，下跌日斜率约−0.00125、接近零；两者差异的HAC检验显著。沪深300在上涨日胜率55.39%，下跌日胜率41.02%。
5. 动态Beta相对固定线性Beta，顺序验证期平方误差下降8.06%，通过相应校正；相对固定非对称Beta的改善约5.41%，但经Holm校正后未达到5%。
6. 连续正负区间和60日速度极值在同步区块零漂移模拟中并不异常；验证期动态创新均值也没有显著正漂移。

**阶段结论：** 两条指数共享市场波动，但共同市场代理只能解释很少的相对收益差方差；上涨与下跌的相对暴露存在明显非对称性。动态Beta对日度条件归因有一定帮助，但没有证明普通交易日存在独立、可持续的相对收益溢价。

## 八、第七阶段：V2多因子归因与动态暴露局部性

**研究问题：** 连续偏移是否由少数区间内的关键日主导？共同市场、涨跌非对称Beta、动态Beta和风格因子分别能解释多少？日度拟合改善能否转化为持有期累计偏移解释能力？

V2仍只研究沪深300与上证综指，沿用2015-01-06至2026-11-17的2,883个日收益。因子共同面板含2,816日，止于2026-08-31。

### 1. 连续区间内部的关键日中和

四个历史60日案例中，区间内部删除最有利的5个交易日后，原有相对领先／落后方向仍然保留：

| 历史区间 | 原始累计相对收益 | 中和区间内最有利5日后 |
|---|---:|---:|
| 2017年强势区间 | +8.10% | +3.84% |
| 2021年初强势区间 | +8.08% | +3.80% |
| 2021年中弱势区间 | −9.15% | −4.26% |
| 2026年弱势区间 | −10.20% | −5.92% |

这说明这些事后选出的典型窗口，不是只靠区间内五个最有利日维持方向。但这些案例不是随机抽样；全部窗口重新搜索、关键日选择和区块模拟校正后，未获得连续偏移异常性的显著证据。

### 2. 相同幅度的领先，收益来源可能不同

2017年和2021年初的沪深300领先幅度都约8.1%，但多因子归因明显不同：

- 2017年规模因子贡献约102bp，模型剩余约663bp。
- 2021年初规模因子贡献约549bp，模型剩余约141bp。

这说明相似的累计相对收益结果，可能对应不同的风格暴露和剩余收益构成。但剩余项不是Alpha，也可能包含遗漏行业因素、指数编制差异、模型误差和随机波动。

### 3. 动态Beta的持有期增量有限

相对于固定非对称Beta模型：

- 随机游走Beta的60日累计平方归因误差仅下降约1.23%。
- 控制风格因子后，动态暴露的额外降幅约1.13%。
- 两项均未通过相应主检验。
- 动态模型的日度误差改善集中在2021年：2021年贡献了相对固定Beta总改善的51.8%，相对非对称Beta总改善的76.0%。

因此，动态Beta的解释能力存在明显时间局部性，不能将日度拟合改善直接理解为持有期收益解释能力。

### 4. 风格控制比动态Beta更有解释力

在CH共同样本中，固定非对称市场暴露加入风格因子后，60日累计均方误差较非对称市场模型降低约40.5%；方向判断准确率从61.0%提高至78.9%。

这是一项具体配对上的条件归因结果，不是事前收益预测，也不是新的全球因子理论。

### 5. 局部截距成为下一阶段线索

60日滚动OLS相对固定非对称Beta模型，累计平方误差降低约40.6%；但与“只更新局部截距、保持市场斜率不变”的对照相比，额外改善仅约4.2%，且不显著（p约0.324）。

这提示滚动OLS的改善可能主要来自局部均值／截距更新，而不是时变Beta本身。但滚动截距可能机械抵消历史误差，尚不能认定存在真实局部收益漂移。

**V2结论：** 现有模型仍留下连续相对价格偏移，但没有证据表明其系统性超出普通市场波动、非对称风险暴露、风格因子和相关残差所能产生的范围。固定风格控制的描述性增量明显，动态Beta在60日持有期评价中的额外增量不足。局部收益中心变化是下一阶段待检验假说，不是V2已经证明的发现。

## 九、截至2026-11-25的学术贡献判断

项目已经形成了一组可复核的A股宽基实证结果，但必须区分“项目发现”与“全球金融学原创贡献”。

### 已经得到数据支持的具体结果

1. 沪深300相对上证综指的长期价格财富优势只有约2.07%，对两个事后最有利交易日敏感；全期日相对收益均值不显著。
2. 九指数36组配对中，长期排名普遍对少量日期敏感，但正贡献集中度并不异常，关键日集中度也没有表现出样本外预测价值。
3. 七指数的关键日期存在一定跨配对重合，但删除共同关键日并没有使全池累计路径普遍趋同。
4. 固定起点路径距离、窗口重置距离和去趋势形状距离可能给出不同结论；七指数后半段局部距离下降没有通过同步区块显著性检验。
5. 沪深300相对上证综指的上涨与下跌市场暴露不对称；风格因素对部分连续持有期偏移的解释明显强于动态Beta。
6. 2017年和2021年初两个相近幅度的相对领先区间，呈现不同的规模因子贡献和模型剩余构成。

### 已经被实验削弱或未获支持的假说

- “沪深300长期稳定跑赢上证综指”：没有得到支持。
- “删除关键日后，九指数／七指数路径会普遍趋同”：没有得到支持。
- “关键日集中度能够预测未来相对风险”：没有得到支持。
- “动态Beta显著优于固定非对称Beta解释持有期累计偏移”：没有得到支持。
- “模型剩余收益就是可交易Alpha”：没有证据支持。
- “滚动窗口拟合改善意味着未来收益可预测”：不成立，至少当前实验没有证明。

### 相对于全球已有研究的定位

关键交易日影响长期业绩、收益路径的连续性与集中性、共同市场因子、时变Beta、规模和价值因子归因、指数跟踪偏离等方向均已有国际研究。项目的指数样本、具体时间段、模型组合和图形展示本身不足以构成全球原创性。

目前较有希望的候选问题是：

**当长期相对排名对少数关键日敏感时，扣除这些日期后，普通交易日组成的连续持有期是否仍存在有经济意义的局部相对收益漂移？在控制共同市场、涨跌非对称暴露和风格因子后，这种漂移能否被事前识别，并为基准选择提供超出现有跟踪误差和固定Beta模型的增量信息？**

这一候选问题仍需与条件Alpha、时变预期收益、基准偏离、局部可预测性及相关收益路径研究进行更完整的文献查重。项目已形成的研究边界审查见[九指数项目立项审核](papers/relative_return_path_paper/research_boundary_review.md)。

### 下一阶段：V3局部相对收益漂移（尚未运行）

当前计划将V2中“动态Beta的额外解释能力不足、局部截距可能重要”的线索转化为可证伪实验：

- 在固定／动态截距与固定／动态Beta之间做正交对照；
- 加入风格因子控制，区分局部收益中心、风险暴露和遗漏变量；
- 用零漂移、自相关、异方差、时变Beta、遗漏风格因子和真实漂移模拟，检查滚动截距是否机械地产生误差改善；
- 区分逐日更新的条件归因与固定预测起点的持有期预测；
- 对关键日、窗口搜索、区块依赖和多重检验作统一校正。

**V3目前是下一阶段研究设计，不是已经完成的实验。** 只有动态截距在严格时序验证中稳定优于简单基准、通过合理零模型并具有经济意义，才有理由将其提升为论文主线。否则应保留负结果并停止增加模型复杂度。

## 十、项目的主要局限

1. **价格指数口径：** 当前核心行情是价格指数，不包含现金分红。不能将价格相对收益直接等同于投资者可实现的全收益。
2. **成分股历史数据：** 连续历史有效成分、权重、行业归属和退市股票覆盖仍不完整。仅凭指数收盘价无法识别行业权重、资金流或指数编制调整的因果机制。
3. **因子覆盖：** CH因子共同样本截至2026-08-31，且存在缺失日期；因子归因只在匹配面板内成立。
4. **样本依赖：** 多组配对共享指数和交易日，滚动窗口高度重叠，不能把配对数或窗口数当成独立样本数。
5. **事后选择：** 关键日、极值窗口和典型时期是历史数据中识别出来的；若模拟不重新执行搜索和筛选，显著性会被高估。
6. **交易可行性：** 指数点位不是可直接成交的金融产品。ETF跟踪误差、股指期货基差、借券券源、保证金、滑点和真实费用仍需单独核验。
7. **文献查重：** 已做定向文献审查，但尚未穷尽所有订阅期刊、中文学位论文和前向引文网络，不能作全球原创性保证。

## 十二、项目当前状态（一句话）

**我们已经较充分地描述了A股宽基指数之间的长期相对收益敏感性、关键日影响、局部路径差异和部分风险暴露；但尚未证明一种独立、可预测、扣除风险因素与交易成本后仍然成立的持续相对收益机制。下一步不是继续堆叠模型，而是严格检验局部收益漂移是否真实、是否可提前识别，以及它相对已有基准模型究竟增加了多少信息。**
